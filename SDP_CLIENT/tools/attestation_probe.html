Windows Hello attestation probe

A browser reaches Windows Hello through the same operating system call this project's client uses. This page asks Hello for a credential with attestation and reports which format comes back, which separates "this machine will not attest" from "our client is asking for it wrongly".

Nothing leaves this machine: the credential is created, read, and discarded here. Serve this file over localhost — browsers refuse WebAuthn from a file:// page.
